📘 Linear Regression with Gradient Descent (from Scratch)
This project demonstrates how to implement linear regression using gradient descent from scratch with NumPy. A simple synthetic dataset is generated, and the model learns to fit a straight line by minimizing the Mean Squared Error (MSE) cost function. The code calculates gradients (dw, db) and updates the model parameters (w, b) iteratively. It also includes a visualization of the cost convergence over iterations using Matplotlib.
